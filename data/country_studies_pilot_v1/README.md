# Country Studies 실자료 파일럿 v1

사용자가 제공한 한국·북한·일본 PDF 3권에서 작성한 한국어 평가 질문 30개입니다. 가상 연구실 예제와 구분되는 실자료 기반 파일럿이며, 실제 모델의 성능 측정 결과는 아닙니다. 중국편은 파일 전달 실패로 포함하지 않았습니다.

## 구성과 집계

| 원문 | 판권면 발행연도 | 원본 PDF 쪽수 | 추출 텍스트 | 질문 split | 문항 수 |
| --- | ---: | ---: | --- | --- | ---: |
| South Korea: A Country Study, 4판 | 1992 | 462 | south_korea.txt | dev | 10 |
| North Korea: A Country Study, 5판 | 2008 | 384 | north_korea.txt | dev | 10 |
| Japan: A Country Study, 5판 | 1992 | 670 | japan.txt | test | 10 |
| 합계 | | 1,516 | 3개 문서 | dev 20 / test 10 | 30 |

사실·수치·비교·복수 근거·답변 불가 유형이 각각 6문항입니다. 답변 가능한 24문항에는 근거 문장 32개가 연결되어 있습니다. 검색 회수율의 분모는 전체 30개가 아닌 답변 가능한 24개이며, 개발용 16개와 최종 평가용 8개입니다.

세 원문 전체를 검색 대상으로 사용합니다. 개발용 질문은 한국·북한, 최종 평가용 질문은 일본으로 나누며 같은 source_group을 양쪽에 넣지 않았습니다. 질문은 국가안보 본문의 선택된 부분을 중심으로 작성했으므로 책 전체 주제를 고르게 평가하는 데이터는 아닙니다.

## 바로 사용하기

개선 코드가 들어 있는 PR #1의 브랜치에서 사용합니다. 배포한 데이터 ZIP 안의 `configs/`와 `data/`를 프로젝트 루트에 같은 경로로 합칩니다. 원본 PDF를 다시 넣을 필요 없이 ZIP에 포함된 UTF-8 추출 텍스트를 읽습니다. 대용량 원문 및 추출 텍스트는 Git 추적 제외 경로에 두었습니다.

```bash
python -m rag_eval validate --config configs/country_studies_pilot_dev.yaml
python -m rag_eval validate --config configs/country_studies_pilot_test.yaml
```

모델을 사용하지 않는 위 검증부터 실행합니다. Ollama가 실행 중이고 `bge-m3`가 준비된 환경에서는 검색 실험을 실행할 수 있습니다.

```bash
python -m rag_eval run --config configs/country_studies_pilot_dev.yaml -v
```

개발용 질문으로 설정을 정한 뒤 `country_studies_pilot_test.yaml`로 최종 평가합니다. 기본은 검색 전용(`llm_models: []`)입니다. 답변 생성과 거부 정확도까지 평가하려면 답변 모델을 지정해야 하며, 자동 채점은 별도 모델을 선택한 뒤 활성화합니다.

## 근거와 원문 추적

- `qa.jsonl`: 한국어 질문·정답·유형·split과 영문 원문 근거. `pdf_page`는 **1부터 시작하는 PDF 파일 쪽수**이며 책에 인쇄된 쪽수와 다릅니다. 이 속성은 원문 확인용이고 검색 정답 판정은 텍스트 위치를 사용합니다.
- `sources.jsonl`: 원본 파일명, 판권면 발행연도, 공식 서지 링크, PDF 및 추출 텍스트 SHA-256, 추출기 버전과 정규화 방식.
- `page_index.json`: PDF 쪽수와 추출 텍스트의 시작·끝 위치 대응.
- `validation.json`: 실제 코드로 검증한 문항 수·근거 위치·청크 도달 가능 여부. 모델 성능 점수는 포함하지 않습니다.

원문은 pypdf로 추출한 뒤 NFC와 줄바꿈만 통일했습니다. 단어 중간의 줄바꿈 하이픈, OCR 철자 오류, 머리말과 쪽수 표기는 자동 교정·삭제하지 않았습니다. 텍스트층에서 읽을 수 있는 내용만 포함하며 사진이나 그림 자체는 포함하지 않습니다. 근거는 이 텍스트에서 그대로 가져왔으며, 모든 근거가 가리키는 PDF 14개 쪽을 시각적으로 대조했습니다. 근거 인용 안에 OCR 분절이 남아 있을 수 있습니다.

구현된 `load_qa`로 근거 32개의 일치와 PDF 쪽수 대응을 확인했습니다. 1000/200 및 800/100 청크 설정에서 모든 답변 가능 문항의 각 근거를 50% 이상 덮는 청크가 존재하는지도 확인했습니다. 이는 **정답 근거가 검색 가능한 형태로 잘렸는지의 검증**이며, 모델이 실제로 상위 k개 안에 검색했다는 의미는 아닙니다.

## 한계와 다음 확장

답변 불가 6문항은 모두 판본 발행 이후인 2026년의 실제 관측치를 요구하는 쉬운 부정 예시입니다. 세 원문 텍스트에는 `2026` 연도 토큰이 없음을 확인했지만, 이것만으로 일반적인 답변 거부 성능을 평가할 수는 없습니다. 같은 시점의 비슷한 항목, 누락된 세부 통계 등을 묻는 더 어려운 부정 예시가 후속으로 필요합니다.

서술·정답은 해당 판본을 기준으로 하며 현재 군사·행정·법률 현황을 뜻하지 않습니다. 비교형 답변의 대소 관계와 관련 합계는 검산했습니다. 문항 수가 작고 사람이 작성한 초도 파일럿이므로 일반 성능이나 통계적 유의성을 주장하지 않습니다.

중국편을 추가할 때에는 원문 집합이 바뀌므로 새 버전을 만들고, v1과 동일한 데이터 조건의 결과로 섞지 않습니다. 실제 실험 결과는 `results/`에 저장하고, 검수된 데이터 자체와 구분합니다.
