# 가상 연구실 장비 사용 규정 (예시 문서)

이 문서는 저장소 동작 확인용으로 작성한 가상의 규정이며 실제 기관과 관계가 없습니다.

## 제1장 총칙

제1조(목적) 이 규정은 연구실 공용 장비의 안전한 사용과 공정한 배분을 위해 필요한 사항을 정한다.

제2조(적용 대상) 이 규정은 연구실에 소속된 학생, 연구원, 방문 연구자에게 적용한다. 방문 연구자는 지도교수의 승인을 받은 경우에만 장비를 사용할 수 있다.

## 제2장 예약과 사용

제3조(예약) 공용 GPU 서버는 예약 시스템을 통해 사용 3일 전까지 예약해야 한다. 1인당 연속 예약은 최대 48시간으로 제한한다.

제4조(우선순위) 학위논문 심사를 30일 이내에 앞둔 사람은 예약 우선권을 가진다. 우선권 사용자는 일반 예약보다 먼저 배정되지만, 이미 시작된 작업을 중단시킬 수는 없다.

제5조(측정 장비) 오실로스코프와 신호 발생기는 사용 후 반드시 전원을 끄고 사용 대장에 이름과 사용 시간을 기록한다.

## 제3장 안전과 위반

제6조(안전 교육) 장비를 처음 사용하는 사람은 연 1회 실시하는 안전 교육을 이수해야 한다. 교육을 이수하지 않은 사람은 납땜 장비를 사용할 수 없다.

제7조(위반 시 조치) 예약 없이 장비를 사용하거나 사용 대장을 기록하지 않은 경우, 1회 위반 시 경고하고 2회 위반 시 2주간 예약을 제한한다.
